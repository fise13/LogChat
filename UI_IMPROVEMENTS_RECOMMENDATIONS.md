## 🔍 Веб-поиск

### 1. **Отображение результатов поиска в чате** ⭐⭐⭐ (КРИТИЧНО)

**Проблема:** Пользователь не видит, какие источники были найдены и использованы AI.

**Решение:** Добавить компонент `SearchResultsCardView`, который показывает:
- Список найденных источников (до 5 результатов)
- Заголовок и краткое описание каждого
- Возможность открыть источник в браузере
- Визуальная индикация, что эти источники использованы в ответе

**Реализация:**
```swift
struct SearchResultsCardView: View {
    let results: [SearchResult]
    let onSourceTap: (URL) -> Void
    
    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            HStack {
                Image(systemName: "magnifyingglass.circle.fill")
                    .foregroundColor(DesignSystem.Accent.primary)
                Text("Found \(results.count) sources")
                    .font(DesignSystem.Typography.subheadline)
                    .fontWeight(.semibold)
            }
            
            ForEach(results.prefix(3)) { result in
                SearchResultRow(result: result, onTap: onSourceTap)
            }
        }
        .padding(DesignSystem.Spacing.md)
        .background(DesignSystem.Background.secondary)
        .cornerRadius(DesignSystem.CornerRadius.medium)
    }
}
```

**Где показывать:** После завершения веб-поиска, перед ответом AI или в свернутом виде с возможностью развернуть.

### 2. **Индикатор количества найденных результатов** ⭐⭐ (ВАЖНО)

**Проблема:** Пользователь не знает, сколько результатов найдено во время поиска.

**Решение:** Обновить `WebSearchIndicatorView` для отображения:
- Счетчика найденных результатов в реальном времени
- Прогресс-бар поиска (если API поддерживает)
- Время поиска

**Пример:**
```

Found 3 results so far...
```

### 3. **Источники в ответе AI** ⭐⭐⭐ (КРИТИЧНО)

**Проблема:** AI использует информацию из веб-поиска, но не показывает источники.

**Решение:** 
- Добавить кнопку "Show Sources" в сообщениях AI, где использован веб-поиск
- Показывать источники в виде чипсов/бейджей под ответом
- При нажатии на источник - открывать в браузере

**Визуализация:**
```
[Ответ AI]

[Sources: source1.com | source2.com | source3.com]
```

## 💡 Визуальная обратная связь

### 4. **Улучшенный индикатор статуса поиска** ⭐⭐ (ВАЖНО)

**Текущее состояние:** Базовый индикатор с текстом.

**Улучшения:**
- Показывать этапы поиска: "Querying...", "Processing results...", "Analyzing..."
- Анимированный прогресс (пульсирующие точки или прогресс-бар)
- Показывать время поиска
- Цветовая индикация: синий (поиск) → зеленый (найдено) → серый (завершено)

### 5. **Toast-уведомления для важных событий** ⭐⭐ (ВАЖНО)

**События для уведомлений:**
- ✅ "Web search completed - found 5 results"
- ⚠️ "Web search failed - continuing without search"
- ℹ️ "Using cached search results"

**Реализация:** Легковесный компонент, появляющийся вверху экрана на 3-4 секунды.
